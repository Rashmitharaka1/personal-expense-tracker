
# SpendMate - Student Expense Tracker

## Project Overview

SpendMate is a simple Flutter mobile application designed
to help university students track their daily expenses.

The application was developed for the Mobile Application
assignment under Scenario 5: Personal Expense Tracker.

## Features

- Display predefined student expense items.
- View detailed information about each expense.
- Add and remove recorded expenses.
- Automatically calculate total spending.
- Display category-wise spending breakdown.
- Display success messages after user interactions.
- Navigate between three application screens.
- Display an empty state when no expenses are recorded.

## Application Screens

### Home Screen

Displays predefined expenses, the total amount spent,
and the number of recorded expenses.

### Expense Details Screen

Displays the selected expense name, category, amount,
and description with an Add Expense button.

### Summary Screen

Displays recorded expenses, total spending, category-wise
spending breakdown, and expense removal functionality.

## Installation and Execution

1. Clone this repository using GitHub Desktop.
2. Open the project in Visual Studio Code.
3. Install project dependencies:

   flutter pub get

4. Run the application:

   flutter run

## Data Storage

The application uses predefined sample expenses and
stores recorded expenses in memory during execution.
No external API, database, backend, or authentication
system is required.
